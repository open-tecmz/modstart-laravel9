## 模块介绍

「后台管理配置」模块是系统后台的基石：提供管理角色、管理员、管理日志等基础后台管理功能，并承载基础权限配置与框架自动升级入口，站点后台的登录、授权与升级都依赖它。

## 功能特性

- 管理角色与管理员的增删改查，按角色分配后台菜单权限
- 管理日志记录后台关键操作，便于审计与追溯
- 基础权限相关配置，统一控制后台菜单与操作入口
- 基础框架自动升级，升级前检测环境并在界面上提示关闭防篡改等安全软件
- 后台仪表盘服务器信息展示：版本号、运行时与参数信息按列对齐，更易读

```mind
后台管理配置
    管理能力
        管理角色
        管理员
        管理日志
    权限
        后台菜单权限
        基础权限配置
    运维
        框架自动升级
        升级前安全软件提示
        仪表盘服务器信息
```

## 使用场景

- 站点后台的多管理员协作：按角色分配不同菜单权限
- 后台操作审计：查询谁在什么时间做了什么操作
- 系统升级维护：在后台检查版本、执行框架升级
- 后台环境排查：仪表盘查看版本、运行环境与参数
