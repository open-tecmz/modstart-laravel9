# 欢迎首页

为 ModStart 站点提供一页干净的介绍型首页：说明框架的模块化能力，并给出后台、开发文档、模块市场的入口。

## 功能

- 首屏展示框架定位与技术栈版本（Laravel / ModStart / PHP）
- 框架特性：全模块化、后台开箱即用、一份代码多版本、内置实现优先、模块市场、多端适配
- 三步启动：`composer install` → 配置 `.env` → `php artisan modstart:init`
- 已启用模块列表：实时读取当前启用的模块
- 快捷入口：后台管理、开发文档、模块市场、官方网站

## 适用场景

- 新站点安装完成后的默认首页，替换掉产品自带的 CMS / 博客首页
- 对外展示「本站基于 ModStart 搭建」的落地页
- 二次开发时作为主题与视图改造的起点

## 特性

- 无数据表、无后台菜单，安装即用
- 响应式布局，PC 与手机共用同一套视图
- 全部样式消费设计令牌，自动跟随站点主色调与深色模式
- 已在后台「首页切换器」注册为可选首页，可随时切回其它首页
