## 模块介绍

「网站基础信息配置」模块提供了网站的基础信息配置

## 功能特性

- 站点基础设置：站点名称、Logo、图标、副标题、备案信息等统一配置
- 支持多主题配置项注入，主题所需参数在后台一处填写
- 设置项带默认值，新装站点开箱即可用
- 兼容最新运行环境（Laravel 13 / PHP 8.5）

## 多主题选项使用

继承 `AbstractSiteTemplateProvider` 实现网站多模板功能 



## 模块入口

- `/site/contact` 联系方式

## 使用场景

- 新站上线时配置站点名称、Logo 与备案信息
- 多主题切换后统一下配置项
- 运营按品牌调整站点基础信息
